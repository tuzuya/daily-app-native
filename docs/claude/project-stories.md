## ① ユウト ―「気づいたら課題が終わっていた」

大学3年のユウトは、課題の締切前夜に焦るのが恒例になっていた。タスク管理アプリは何度も入れたが、開くたびに未完了の赤い文字が並んでいて、そのうち開かなくなった。

ある日、SNSで「タスクをこなすとアバターが育つアプリ」を見かけてインストールする。最初に出てきたのはタスク登録画面ではなく、アバター作成だった。髪型や表情を選んでいるうちに、少し愛着が湧いてくる。

「とりあえず今日やることを1つだけ」と促されて、「洗濯する」を難易度「かんたん」で登録した。洗濯機を回して完了ボタンを押すと、アバターが小さくガッツポーズをして、questの経験値バーが伸びた。たったこれだけのことなのに、ちょっと嬉しい。

1週間後、ユウトはゲームのデイリーを消化する流れでこのアプリも開くようになっていた。レポートは「むずかしい」で登録すると経験値が大きい。レベルアップ目前のアバターを見て、「あと1つ終わらせればレベル5」と思い、気づいたら課題を片付けていた。**タスクを「やらなきゃいけないこと」ではなく「経験値の素材」として見るようになった**のが、いちばんの変化だった。

**体験の要点:** 初回はタスク登録より先にアバター作成 / 最初のタスクは1つだけ促す / 完了時にアバターのリアクション＋経験値バーが伸びる / レベルアップ目前の可視化が行動を後押しする

## ② ミサキ ―「自分を後回しにしない日が増えた」

在宅で働くミサキは、仕事は順調なのに、気づくと昼食を抜き、一日中外に出ずに終わる日が続いていた。

友人に勧められてアプリを入れると、タスクのカテゴリに「recovery」があることに気づく。試しに「昼ごはんをちゃんと食べる」「10分散歩する」を登録してみた。仕事のタスクを管理するアプリで、こんなことを書いていいとは思っていなかった。

散歩から帰って完了を押すと、アバターがのびのびした表情になり、recoveryの経験値が溜まった。夕方、画面を開くと、今日は仕事だけでなく自分のケアもできていたことが一目でわかる。

何もできなかった日もあった。でもアプリは責めてこなかった。未完了のタスクは静かに翌日に回り、アバターはいつも通りそこにいた。1ヶ月後、recoveryのレベルが仕事系のタスクと同じくらいに育っているのを見て、ミサキは**「自分を大事にするのも、ちゃんと積み上がるんだ」**と思えるようになった。

**体験の要点:** セルフケアをタスクとして書いてよいと伝わるカテゴリ / recovery完了でアバターの表情が変わる / 未完了は責めずに静かに翌日へ回す / カテゴリ別の成長が見える

## ④ ナオコ ―「見えなかった頑張りが見えるようになった」

2人の子どもを育てながらパートで働くナオコは、毎晩「今日も何かしていたはずなのに、何も残っていない」と感じていた。

アプリを入れたものの、正直、タスクを毎回入力するのは面倒だと思っていた。ところが最初の設定で「毎日の家事」をいくつか繰り返しタスクとして登録しておけば、あとはやったものをタップするだけでいいとわかった。朝食の片付け、洗濯、連絡帳チェック。家事の合間に1タップずつ押していく。

子どもを寝かしつけた21時半、アプリを開くと、今日こなした10個以上のタスクが並び、アバターが一日分成長していた。誰も褒めてくれなかったけれど、この画面は確かに「今日よくやった」と言っているように見えた。

ある日、娘が画面を覗き込んで「このキャラ、ママなの？ 強くなってるね」と言った。**名前のなかった家事が、目に見える成長になった**瞬間だった。

**体験の要点:** 繰り返しタスクで入力の手間をなくす / ワンタップ完了 / 一日の完了一覧とアバターの成長で「今日よくやった」を伝える
