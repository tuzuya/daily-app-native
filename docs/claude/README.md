# docs/claude — Claude Code に読ませる資料の置き場

Claude Code がタスクに応じて参照する Markdown をここにまとめる。
プロジェクト全体の引継ぎ（技術スタック・データモデル・ビジネスロジック）はリポジトリ直下の `CLAUDE.md` が正本で、
ここには「必要なときだけ読めばよい」詳細資料を置く。

| ファイル | 内容 | 読むべき場面 |
|---|---|---|
| [ui-ux-design.md](ui-ux-design.md) | ビジョン・コンセプト・ターゲット・スコープ・トンマナ・アイデアメモ | UI/デザイン/機能の優先度を判断するとき |
| [personas.md](personas.md) | ペルソナ3人（ユウト・ミサキ・ナオコ）と比較表 | 機能・文言・演出がユーザーに合うか判断するとき |
| [project-stories.md](project-stories.md) | ペルソナごとの利用ストーリー | 体験フロー・演出を設計するとき |

## 運用ルール

- 出典が Notion の資料は、冒頭に**出典URLと取得日**を書く。Notion 側を更新したら、ここも取り直す
- Notion の記述をそのまま写した部分と、Claude が補足した部分（「Claude メモ」）は区別して書く
- 新しい資料を追加したら、この表に1行足す
