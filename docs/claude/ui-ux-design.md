## ビジョンとゴール

タスク管理をするためにアプリを意識的に使うのではなく、**育成ゲームをする感覚でタスク管理を自然にできるようになる**こと。
また、タスクのモチベーションもそれに合わせて向上させられること。

## コンセプト

**「あなた自身を、育成しよう」**

## ペルソナ

→ [personas.md](personas.md)

## ターゲットとニーズ

- **ターゲット**
  - タスク管理（入力、日常的な操作）が苦手
  - タスク消化（モチベーション維持）が苦手
  - 自分のケア（休憩や息抜き）が苦手
- **ニーズ**
  - 手軽にタスク管理がしやすい
  - タスク消化のモチベーションになる
  - 自分のケアを意識できるようになる

## スコープ

| 段階 | 内容 |
|---|---|
| **MVP** | アバター作成とその成長、そして実生活のタスク消化が合致する機能。手軽なタスク管理。＋関連する魅力的なUI/UX |
| 第二弾 | ガチャ機能、コレクションによってモチベ向上を狙う |
| 第三弾 | キャラクターの戦闘機能 |

MVPの補足（Notion原文の強調点）:

- 育成ゲームなら、**アバターに愛着を持ってもらう必要がある**。作り込みたい
- recovery タスクのクリアでアバターの表情が明るくなる、など**アバターの挙動の変化**もあったほうが良い

## 思いつきのアイデア（未決定のメモ）

- 女性ユーザーは可愛いキャラの育成の方を好む可能性があるので、アバターにスライムや動物などのキャラクターを追加
- タスク消化の主軸が「Today」に集中しているのが気になる。生活リズムが不規則なユーザーは使いにくそう
- アバターの成長を感じるUIが欠けている。経験値を獲得しても、種類ごとのステータスが本当に成長しているのかわかりにくい。いちいちステータス画面を見に行かないといけないのは✖︎
  → 経験値バーが伸びるUIや、アバターのレベルアップのUIを実装する
- NextやOverdueが溜まってくると、後でTodayに持ってくる時にいちいち探すのが面倒
-> 目標とする日付などから、優先度・緊急度順で並んでいたらまだマシかも

## 意識したいこと（ハッカソンでの学び）

- 「AIでできること」をそのままコンセプトにしても、ChatGPTで良いと思われたら終わり。AIでできないこと・やりにくいことを組み込みたい
- ターゲット像を具体的にすることが大事。なんとなくではなく、ペルソナをしっかり決める
  （実際にそんな人はいるのか、本当に使ってもらえるのか、どんな機能要件なら使ってもらえるかのイメージが膨らむ）
- viewer で開いたときにルーティング先のファイル名がそのまま出ているのはマイナスイメージなので注意
